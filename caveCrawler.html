Cave Crawler

Unity · Team project

Implemented deterministic procedural generation and on-demand terrain chunks in Unity, plus deployable objects that modify the environment.

  • Overview

    Cave Crawler is a team-built mining game in Unity. My engineering work focused on deterministic terrain generation, generating chunks as the player moves, and deployable items that interact with the terrain.

  • Engineering contributions

    I implemented deployable torches and bombs with resource costs and limited starting quantities. Torches illuminate nearby terrain; bombs destroy mineable blocks within their area of effect.


    I implemented seeded procedural terrain generation so the same seed reproduces the same map. Terrain is divided into chunks, with neighboring chunks generated when the player enters a new area. This supports continued exploration while avoiding generating the entire map upfront.
