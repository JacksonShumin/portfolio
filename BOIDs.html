GPU BOIDs

Unity · Solo project

A GPU-parallel agent simulation exploring flocking algorithms, computational cost, and mesh complexity in Unity compute shaders.

  • Parallel agent simulation

    I implemented a flocking simulation in Unity compute shaders to explore parallel agent updates on the GPU. The initial experiment simulated approximately 32,000 agents following local flocking rules.

  • BOIDs

    The BOIDs work by following a few simple rules. They avoid nearby BOIDs, move toward the center of the flock, and try to match velocities with other nearby BOIDs. I included a box to act as bounds that they would avoid and get teleported to the other side should they cross it.

  • Configurable agent behavior

    I added a distinct agent type with different attraction and avoidance weights to explore heterogeneous behavior within the same simulation. Other agents strongly avoid it while it moves toward the flock center. It uses a larger, higher-detail mesh to make its behavior visible.


    Optimization

    I reduced computation through short-circuit evaluation and avoiding square roots where possible. Replacing the standard agent mesh with a triangular pyramid also reduced geometry cost. I removed boundary teleportation after observing that it disrupted flock behavior. Together, these changes allowed the second experiment to simulate roughly twice as many agents.
